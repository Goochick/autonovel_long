# 语声档案：《我在死灵地精的神国种蘑菇》

---

## Part 1: Guardrails（永久规则）

### Tier 1: 绝对禁用词（出现即改）
| 禁用词 | 替代建议 |
|--------|---------|
| 不由得 | 直接写动作 |
| 竟然 | 直接写出事实 |
| 缓缓 | 用"慢慢"、"一点一点"、"一步三晃" |
| 轻声/柔声 | 直接写对方说话的样子 |
| 微微一笑 | 嘴角咧一下、鼻子哼一声、表情崩住 |
| 意味深长 | 具体描写对方的眼神或动作，比如"他盯着那株蘑菇看了三秒" |

### Tier 2: 聚集可疑词（单个可用，一段出现3个必须重写）
- 深入了解、有效利用、促进、推动 → 改成"把人家的家底翻了个遍"、"用这玩意儿干了好几票"、"让它滚起来"
- 众所周知、毋庸置疑 → "谁都知道"、"明摆着"
- 深邃、复杂、若有所思 → 具体写想法，别装深沉

### Tier 3: 废话短语（直接删除）
- 不得不说、相信大家都知道 → 删
- 值得注意的是、从某种程度上说 → 删
- 事实上、老实说 → 删，除非角色故意装傻

### 结构性AI味模式
- 段落模板化（Topic→Elaboration→Example→Wrap-up）→ 打乱节奏，有时候直接甩例子，有时候只给结论
- 句子长度均匀 → 交错用：短三句，长一句，再来一句极短的
- 过渡词上瘾（然而、此外、与此同时）→ 换成"结果"、"回头一看"、"这边还没完"
- 对称强迫症（三个优点、三个缺点）→ 写一个就够了，剩下的靠场景带
- 犹豫词游行（可能、也许、大概）→ 要么肯定，要么不确定但用行动表现

### 中文网文特有AI味检测
- "不禁"/"竟然"/"居然" 过度使用 → 删成零星的，保持在一章3次以内
- "嘴角微微上扬""眼中闪过一丝xxx" → 改成"嘴一咧"、"眼珠子转了转"
- "一股xxx的气息""仿佛xxx一般" → 写实际的感受，比如"那味儿像放了三个月的死老鼠"
- 每段结尾都总结升华 → 总结可以，但用角色吐槽收尾，别搞哲理

## Part 2: Voice Identity

### 基调

**黑色幽默种田，泥巴里炸出传奇。**

像有人蹲在死人堆里种蘑菇，一边嫌弃环境恶心，一边发现蘑菇炸人特别爽。节奏扯淡但不拖沓，爽点密集但带点自嘲。对话时像两个损友瞎扯，打斗时像看搞笑片——主角被炸上树也算战斗场面。

不用宏大辞藻，不用煽情渲染。脏话适当，吐槽管够，搞怪第一，节奏第二，深度第三（如果写不进去就放弃）。

---

### 句式节奏

**原则：能短就短，长句只用在吐槽和翻旧账。**

- 动作场面：3-7字一句。快。
  - “他跑。” “蘑菇炸了。” “脸黑了。” “哦。”
- 种田/日常：12-20字一句，偶尔来一段长句吐槽（不超过40字，一生只写一次长的）。
  - 示例：“灰鼻子说这玩意儿得种三个月，李默想了想自己三个月能不能活过第一周，决定先种一亩炸着看。”
- 装逼打脸：短句收尾，短到只剩一个词。
  - “那使者被炸进粪坑了。” “就三秒。”

**节奏模板**：
1. 种田时：慢 → 快（想着丰收开始激动）
2. 打架时：短 → 短 → 短 → 一个小长句（发现不对） → 极短（爆炸）
3. 吐槽时：中长句铺垫 → 极短句收尾（包袱）

---

### 词汇调性

**用：** 具体动作词
- 种、炸、砍、跑、踢、翻、掏、啃、骂

**不用：**
- 获取 → 搞到、偷来、抢来
- 进行处理 → 弄、搞、整
- 实现目标 → 搞定了、成了

**特色用词（这本书专属）**：
- 蘑菇 = 屎蘑菇（生气时）、宝贝（得意时）、那玩意儿（中性）
- 亡灵 = 骨头架子、死鬼、僵尸兄、毛
- 敌人 = 傻X、废物、穿白衣服的、教廷那帮
- 系统 = 破系统、金手指、挂
- 沼泽 = 泥巴坑、死水洼、坟场

**拟声词大量使用**：
- 蘑菇炸：轰隆、嘭、啪叽
- 骨头走路：咔嗒咔嗒、嘎吱
- 地精说话：唧唧歪歪、咕噜噜

---

### 对话风格

**标签**：只用“说”，或者用动作代替。

**角色声音区分**：

| 角色 | 说话方式 |
|------|---------|
| 李默（主角） | 痞气，句尾带“呗”、“啊”、“懂了不”。吐槽多，嘲讽居多。遇到正经事时秒变战地记者语气。 |
| 灰鼻子（老铁匠） | 闷葫芦，五个字内说完，说完就走。偶尔崩出一长句，一定是在骂人。 |
| 小白菜（骷髅） | 咔嗒咔嗒的骨头声，李默翻译成正常话。天然呆，话多，常从奇怪角度提问。 |
| 路西法妮拉（暗精灵） | 高冷，但说话时总带着讽刺。用词考究，但每次说完都要补一句“你懂个屁”。 |
| 教皇（反派） | 装逼犯，每句话都要搞个大排比，然后被李默打断。 |

**对话特点**：
- 不啰嗦，说三句没到重点就被人怼
- 吵架时像相声，捧哏和逗哏交替
- 战斗时对话极短，通常是“跑”“炸了”“退”“草”

### 示例段落

**1. 种田场景（第一株蘑菇）**

李默蹲在那堆骨头面前，手里攥着那粒灰扑扑的种子。他低头看了看，抬头看了看那些不知道死了多少年的骷髅。

“哥们，借你的窝用用。”

他把种子塞进骨头缝里，抠了点泥巴糊上。

等了五秒。没动静。

等了十秒。没动静。

李默趴下闻了闻——有股腐肉和泥土混在一起的味道，但这味道他不讨厌。他砸了砸嘴，把那粒种子往更深处抠了抠。

“咚。”

泥土里传来一声闷响，像心跳。

那粒种子爆开了。一根紫色的菌丝从骨头缝里拱出来，以肉眼可见的速度膨胀——三秒不到，变成一株巴掌大的蘑菇，闪着磷光，正冒着黑烟。

李默凑近看，蘑菇帽子上还刻着两个字：“你好。”

“……系统你逗我呢？”

**2. 战斗场面（亡焰菇首秀）**

五个地精王庭士兵站在十米外，举着铁矛，一脸色厉内荏。

“死灵地精，”领头那个舔了舔干裂的嘴唇，“跪下，缴清流放税。”

李默站起来，拍了拍裤腿上的泥。

“流放税是什么？”

“就是买命钱。没有的话我们送你一程。”

“哦。”

李默转身就跑。那五个士兵愣了一秒——他跑了两步，蹲下，从泥地里捧出一把拇指粗的蘑菇。

紫色蘑菇。

他回头笑了：“送你们点特产。”

扔出去。

蘑菇落地，炸了。

轰——！

紫色的火球把那五个人裹进去，地上多了一个三米大的坑，冒烟。领头的士兵只剩半只手挂在坑沿，指甲还在抖。

李默走过去，蹲下来，把那只手扯下来丢进嘴里啃了一口。

“不好吃。”

**3. 日常吐槽（和李茜法妮拉）**

“你种的这个东西，”李茜法妮拉用两根手指捏起那株发紫光的蘑菇，脸皱成一团，“是认真的？”

李默没抬头，继续往新培养基里撒种子：“咋了，不好看？”

“它会冒烟。”

“会冒烟说明没坏。”

“它冒出的是骷髅形状的烟。”

李默停下手中的活儿，抬头看了看。蘑菇帽子上确实飘出一缕紫烟，在空气里凝成一颗小骷髅头的形状，飘了三秒才散。

“……行了，有特色。”

“你的特色是到处冒死人头。”

“你不觉得挺酷的吗？”

她直接把蘑菇丢回他怀里：“我觉得你再种这种东西，沼泽里的鬼魂大老远就能闻到你，明天教廷的圣骑士就会过来净化你。”

李默把那株蘑菇重新插进骨头堆里，拍了拍手：“那不是更好吗？省得我去找他们。”

李茜法妮拉沉默了五秒，转身就走。

“喂，你这什么反应？”

她的声音从远处飘回来：“我回去写遗书。”

**4. 装逼时刻（对着教廷使者）**

使者穿着白金色圣袍，站在沼泽边缘，两脚上的白布鞋已经沾满了黑泥。他身后的十二个圣殿骑士全副武装，个个表情严肃，看起来随时准备净化这片脏地方。

李默带着小白菜从沼泽里走出来，头上还顶着一片枯叶。

“死灵地精，李默？”

“是我。”

“奉教会教皇冕下之命，要求你在一周内——”

李默从小白菜的肋骨缝里掏出三株亡焰菇，随手丢在使者脚下。

使者低头看了看：“这是什么意思？”

“送你三朵蘑菇。”李默伸出一根手指，“第一个是提醒。第二个是警告。第三个——”

他又从骨头缝里掏出五株亡焰菇，堆在一起。

“——是行动。”

那使者盯着那排蘑菇看了三秒，脸色变了。

“你疯了？你想和教会——”

“不想。”李默拍了拍手上不存在的灰，“我只是想让你们知道，下次再来，我种的不止是蘑菇了。”

“你还想种什么？”

“教会的墓碑。”

### 反例段落（并说明问题）

**反例1：太软了，像散文**

“亡灵能量在沼泽中流淌，如同无声的潺潺溪流。李默蹲在骸骨旁，心中涌起一种奇异的感动。这些曾经的生命，如今化为蘑菇的培养基，竟有了另一番意义。他不禁轻轻叹息，生命真是奇妙的造物，死与生之间，原来也可以这样交织共生。”

**问题：**
- 用了“不禁”
- 用了“轻轻叹息”，地精不这么说话
- 词汇太文雅（潺潺溪流、奇异的感动、交织共生）
- 情绪太高深，主角不会在这种场合思考生命意义
- 节奏慢得像在写散文

**反例2：太严肃了，像历史课**

“地精王庭对死灵地精的歧视有其历史根源。自诸神之战以降，亡灵魔法被视为不祥之兆，死灵地精因此遭受了长达千年的系统性压迫。李默的到来，无疑是打破这一历史枷锁的关键契机。他必须充分利用系统的力量，才能扭转死灵地精的命运。”

**问题：**
- 用了“充分利用”，AI味重
- 段落句式模板化（历史背景→现状→主角使命→升华）
- 没有场景感，像在写设定简介
- 节奏僵硬，每一句都在输出信息
- 没有黑色幽默，没有地精味儿

**反例3：太啰嗦了，像说明书**

“种植亡焰菇的过程相当简单。首先，你需要准备一立方米以上的骸骨作为培养基。然后，从系统中领取原始孢子，将其植入骸骨缝隙中。接着，输入死灵魔力。最后，等待七天后即可收获，每颗基产三到五个蘑菇。”

**问题：**
- 用了“首先……然后……接着……最后”，说明书写法
- 没有对话，没有场景，没有吐槽
- 字数太多，不如直接写“李默往骨头堆里塞了颗种子，七天后来收蘑菇”
- 漏掉了黑色幽默——比如种的时候蘑菇爆开的意外

**反例4：太做作了，像中二台词**

“神国？呵，我李默从来不信什么神。我只信自己手中的泥土，和泥土里种出的每一朵蘑菇。这些看似弱小的植物，将是我颠覆这个世界的力量。终有一天，我要让整个大陆都匍匐在我的种植园前！”

**问题：**
- 太正经了，像热血少年漫的台词
- 主角不会这么说话——他更可能说“蘑菇挺好用的”或者“干了这票再说”
- 没有生活气息，没有细节
- 没有槽点——主角不会这么严肃地给自己开誓师大会

---

**总结：本书语声的目标是——**

**让读者笑出声，然后觉得爽。**

不要高深，不要煽情，不要试图用华丽语言表达复杂的主题。像两个损友边喝啤酒边听你吹牛，讲你怎么在死人堆里种蘑菇，然后把看不起你的人炸进了粪坑。故事可以荒诞，但不能无聊；角色可以倒霉，但不能矫情。

**一句话概括这本书的语声：泥巴里长出来的粗粝幽默，炸出来的畅快人生。**
