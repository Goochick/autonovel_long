# 主线大纲：《我在死灵地精的神国种蘑菇》

## 一、全书概述

### 【核心矛盾】
一个被迫流放的死灵地精，依靠死亡种田系统在白骨沼泽崛起，对抗光耀教会的种族清洗与地精王庭的背叛，最终必须选择：成为新的死亡神祇，还是封印神骸，带领被压迫种族建立属于自己的神国。

### 【主角成长路线】
**起点**：被家族流放到白骨沼泽的17岁死灵地精，体质孱弱、一无所有，濒临饿死
**终点**：要么升格为统御死亡神国的神明，要么成为机械神国的缔造者，打破种族歧视、建立新秩序

### 【预计总字数与卷数】
- **总字数**：约300万字
- **总卷数**：4卷
- **章节数**：约600章（每章5000字左右）

### 【品类标签】
异界后宫/种田经营/亡灵崛起/逆袭打脸/系统流

- **开始**：饿到头晕的流放者，生命值仅剩30%，被5个地精王庭士兵追杀

   - **揭示**：地精王庭早已投靠教会
   - **伏笔F02回收**：第1章士兵身上的教会标记

5. **第65-70章：首遇暗精灵**

   - 提出交易：用情报换取吸魂藤净化剂
   - **转折点**：主角第一次接触外界势力，意识到自己的价值

#### **转折点：第70章**
莉莉安·白蔷薇（教会第七圣女）被派来暗杀主角，但她发现主角能治疗被圣光腐蚀的亡灵生物，产生动摇。她假装受伤混入基地，却无意中看到主角种植园的“圣光-亡灵复合实验”，认出这是自己一直在研究的课题。

#### **本卷结尾（第80章）**
- 地精王庭联合教会发动“边界净化行动”，1500人联军逼近沼泽边缘
- 莉莉安在最后一刻背叛教会，用圣光照亮联军防线，主角趁机引爆300株亡焰菇
- 联军溃败，但主角也暴露了位置
- **结局**：沼泽上空的瘴气被爆炸冲散，露出一座远古地精陵墓的入口
- **悬念**：陵墓里有什么？教会的真正目标是什么？

### 第4卷：神国降临

- **结束**：要么升格为神要么成为凡人的领袖，但已彻底改变大陆格局

**第一幕：神国的碎片（第481-520章）**

   - **转折点**：主角决定切断与系统的联系，开始研究“反系统程序”

   - **转折点**：莉莉安毫不犹豫地选择献出力量

## 四、抗击“稳定性陷阱”措施

### 1. **不可逆的变化**
- **灰鼻子死亡**（第480章）：无法复活，他的死是主角成长的催化剂
- **小白菜牺牲**（第555章）：即使主角成神也无法复活亡灵，因为神骸规则不允许
- **莉莉安失去圣光**（第510章）：她永远失去了圣女的力量，只能靠亡灵魔法生活
- **主角与系统的切割**（第510章）：无论选择哪条线，系统都将消失

### 2. **糟糕的事情保持糟糕**
- **地精王庭的损失**：即使主角建国，王庭的平民也不会完全接纳死灵地精，种族仇恨需要几代人消解
- **暗精灵诅咒**：路西法妮拉虽然成为女王，但前女王留下的诅咒让她必须每10年承受一次“暗影涅槃”（极其痛苦）
- **教会的残党**：即使教皇死亡，教会的地下势力依然存在，偶尔发动恐怖袭击

### 3. **强迫不可逆转的决定**
- **第575-585章**：主角必须在“牺牲路西法妮拉”和“牺牲自己”之间选择，没有第三条路
- **第596-600章**：选择成神线→永远失去凡人生活；选择机械线→永远无法获得神的力量，寿命有限
