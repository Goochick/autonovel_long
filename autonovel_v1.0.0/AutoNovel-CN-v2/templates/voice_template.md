## Part 1: Guardrails (永久规则，所有小说通用)

### Tier 1: 绝对禁用词（出现即改）

| 禁用词 | 替代建议 |
|--------|---------|
| 不由得 | 直接写动作 |
| 竟然 | 换个表达方式 |
| 缓缓 | 用"慢慢"或直接描写 |
| 轻声/柔声 | 标注说话方式的其他方法 |
| 微微一笑 | 嘴角动一下、表情变化 |
| 意味深长 | 具体的眼神/动作 |
| 深邃 | 直接描写 |
| 复杂 | 说清楚复杂什么 |
| 瞳孔骤然放大 | 具体的震惊表现 |
| 倒吸一口凉气 | 直接删或换 |

### Tier 2: 聚集可疑词（单个可用，一段出现3个必须重写）

- 深入了解、有效利用、促进、推动
- 众所周知、毋庸置疑
- 深邃、复杂、若有所思
- robust、comprehensive、seamless
- empower、foster、enhance、elevate

### Tier 3: 废话短语（直接删除）

- 不得不说、相信大家都知道
- 值得注意的是、从某种程度上说
- 实际上、从实际来看
- 值得一提的是

### 结构性AI味模式（任何语声都要避免）

- ❌ 段落模板化（Topic→Elaboration→Example→Wrap-up）
- ❌ 句子长度均匀
- ❌ 过渡词上瘾（然而、此外、与此同时）
- ❌ 对称强迫症（三个优点、三个缺点）
- ❌ 犹豫词游行（可能、也许、大概）
- ❌ Em Dash 超载（每段>2个破折号）

### 中文网文特有AI味检测

- "不禁"/"竟然"/"居然" 过度使用
- "嘴角微微上扬""眼中闪过一丝xxx"
- "一股xxx的气息""仿佛xxx一般"
- 每段结尾都总结升华
- "他不由得握紧了拳头"

### The Smell Test

写完后自问：
- 读出来像不像人说话？
- 有没有让人意外的句子？
- 说的是不是具体的事？

## Anti-Patterns 检测要点

以下12种结构级毒点必须避免：

1. **画蛇添足过度解释**：情绪爆发后不能解释情绪
2. **机械三元组排比**：连续三个短句/三连并列
3. **否定句式病态重复**：单章最多1次"他没有"
4. **报流水账空洞思考**：不要"他想到X、Y、Z"
5. **拐杖式疯狂比喻**：单章最多2次"就像"
6. **分隔符偷懒**：单章最多2次分隔符
7. **段落长度同质化**：禁止连续3个相同长度段落
8. **预设情感曲线**：必须有意外情绪
9. **鬼打墙章节结尾**：每章结尾必须专属定制
10. **对话辩证排比**：禁止多角色共用同一修辞句式
11. **台词书面说明文**：禁止完美句子、要有瑕疵
12. **宏观微观失衡**：70%以上必须微观主现场
