# canon.md (绝对真理库)

关于小说世界的硬事实数据库。此处的每一条记录都是评估模块用于交叉比对的强约束条件。如果正文剧情与此文件中的任何一条真理相冲突，即判定为系统 Bug。

此文件在基础构建和初稿编写阶段会动态生长。每当在 `world.md`、`characters.md` 或某个正文章节中确立了一个硬事实，它就会被作为真理条目记录在此。

---

## 使用规范

- **条目格式**：每一条记录必须是一句简短、可被证伪的陈述，并明确标注信息来源
- **组织形式**：按类别归类。保持结构扁平、易于检索
